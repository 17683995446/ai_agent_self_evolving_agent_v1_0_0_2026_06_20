## 1. 项目概述

### 1.1 设计目标

本项目实现了一个基于第一性原理的自驱永续进化预测修正Agent系统。系统核心逻辑遵循大脑仿生模型：感知环境 -> 内生动机 -> 自主确定行为 -> 多层预测 -> 比对现实误差 -> 修正模型 -> 迭代进化。

### 1.2 核心特性

- **自驱运行**：零人工输入，自主孵化任务
- **多层预测**：底层高频微预测、中层趋势预测、高层抽象预测
- **双闭环进化**：在线实时预测修正 + 离线复盘模型进化
- **安全护栏**：资源约束(CPU<=20%, 内存<=20%)、行为安全约束、探索止损机制
- **异常容错**：关键路径全try-except兜底，极端场景平稳运行

## 2. 系统架构

### 2.1 目录结构

```
self_evolving_agent/
├── src/                    # 源码目录
│   ├── core/               # 核心引擎（状态机、事件总线、配置管理）
│   ├── perception/         # 感知层（系统传感器、日志传感器、文件传感器）
│   ├── prediction/         # 预测层（ARIMA、指数平滑、分层预测）
│   ├── drive/              # 驱力层（安全驱力、收益驱力、能效驱力）
│   ├── task/               # 任务层（任务生成、评分、选择、执行）
│   ├── memory/             # 记忆层（短期记忆、长期记忆、复盘引擎）
│   ├── safety/             # 安全层（资源护栏、行为护栏）
│   ├── optimization/       # 优化层（快照管理、自动回滚、微优化）
│   ├── dashboard/          # 监控层（HTTP仪表盘）
│   ├── monitoring/         # 监控层（日志聚合、异常检测）
│   ├── cli/                # 命令行入口
│   └── utils/              # 工具模块
├── tests/                  # 测试目录（与src一一映射）
├── config/                 # 配置文件（dev/test/prod）
├── docs/                   # 文档目录
├── scripts/                # 部署脚本
├── assets/                 # 静态资源
├── Dockerfile              # 容器构建文件
└── docker-compose.yml      # 容器编排文件
```

### 2.2 核心数据流

```
感知层(perception) -> 状态向量(state_vector)
  -> 预测层(prediction) -> 低/中/高层预测
    -> 误差评估(error_evaluator) -> 误差向量
      -> 驱力层(drive) -> 总奖励值 + 差距向量
        -> 任务层(task) -> 任务生成/评分/选择/执行
          -> 记忆层(memory) -> 样本存储/复盘
            -> 优化层(optimization) -> 快照/回滚/微优化
              -> 安全层(safety) -> 资源/行为检查
```

## 3. 核心模块说明

### 3.1 感知层（Perception）

| 模块 | 职责 |
|------|------|
| SystemSensor | 采集CPU、内存、磁盘、网络、进程、负载指标 |
| LogSensor | 扫描日志文件，统计错误/警告数量，计算趋势 |
| FileSensor | 监控文件系统变化，计算目录统计信息 |
| StateVector | 聚合所有传感器数据，构建统一状态向量 |

### 3.2 预测层（Prediction）

| 模块 | 职责 |
|------|------|
| LowLevelPredictor | 底层高频微预测（ARIMA模型） |
| MidLevelPredictor | 中层趋势预测（指数平滑） |
| HighLevelPredictor | 高层抽象预测（策略推荐） |
| MultiPredictor | 多指标统一预测管理 |
| ErrorEvaluator | 预测误差评估（MAE/MAPE/RMSE） |

### 3.3 驱力层（Drive）

| 驱力 | 说明 |
|------|------|
| Reward_safe | 安全驱力：系统稳定性、资源使用安全 |
| Reward_gain | 收益驱力：任务执行成功率、预测精度提升 |
| Reward_eff | 能效驱力：CPU/内存使用效率 |

### 3.4 任务层（Task）

| 模块 | 职责 |
|------|------|
| TaskGenerator | 基于差距向量自主生成任务 |
| TaskScorer | 多维度任务评分 |
| TaskPool | 任务池管理（上限控制、过期清理） |
| TaskSelector | 探索-利用平衡选择（默认30%探索） |

### 3.5 记忆层（Memory）

| 模块 | 职责 |
|------|------|
| ShortTermMemory | SQLite存储近期样本（默认10000条） |
| LongTermMemory | 长期经验存储接口 |
| ReviewEngine | 离线复盘引擎，价值评分 |
| ValueScorer | 样本价值评分 |

### 3.6 安全层（Safety）

| 模块 | 职责 |
|------|------|
| ResourceGuardian | CPU/内存/磁盘资源监控 |
| BehaviorGuardian | 路径安全、行为约束检查 |
| SafetyEnforcer | 统一安全 enforcement |

### 3.7 优化层（Optimization）

| 模块 | 职责 |
|------|------|
| SnapshotManager | 模型快照创建、加载、验证 |
| AutoRollback | MAE退化自动回滚 |
| MicroOptimizer | 预测器参数微优化 |
| FeatureManager | 特征评估与晋升 |
| RestructureTrigger | 模型重构触发判断 |

## 4. 技术规范

### 4.1 编码规范

- **命名**：变量小写下划线，类名大驼峰，常量全大写下划线
- **语法禁用**：永久禁用 `*args`、`**kwargs`、`eval`、`exec`、裸字符串 `os.system`
- **继承**：全部业务类显式继承 `abc.ABC`，必须定义抽象方法
- **函数行数**：单个函数有效代码行数不超过7行
- **类型注解**：所有入参出参强制添加类型注解
- **全局变量**：禁止任何全局可变变量
- **硬编码**：禁止硬编码常量，全部移入 `constants.py`

### 4.2 文档规范

- 类与全部公有方法必须编写标准文档注释
- 包含四项内容：`:param`、`:type`、`:return`、`:rtype`

### 4.3 接口规范

- 全局预设固定错误码枚举
- 所有接口入参强制完成参数强校验
